# Общий блокнот

Одностраничный сайт на GitHub Pages: **один человек пишет текст — все, кто открыл страницу, видят его сразу**, без перезагрузки.

Живой сайт: <https://dimidrol2252.github.io/>

GitHub Pages отдаёт только статические файлы, поэтому «общее» состояние хранится снаружи —
в публичных MQTT-брокерах, доступных по WebSocket. Брокер запоминает последнее сообщение
(*retained*), поэтому новый посетитель получает текущий текст сразу при заходе.
Своего сервера, регистрации и оплаты не требуется.

## Как пользоваться

| Роль | Ссылка | Что делает |
|---|---|---|
| Редактор (ваш ПК) | <https://dimidrol2252.github.io/#admin> | видит поле ввода, публикует текст |
| Читатели | <https://dimidrol2252.github.io/> | видят текст живьём, редактировать не могут |
| Диагностика | <https://dimidrol2252.github.io/?diag=1> | показывает, до каких брокеров сеть дотянулась |

Текст публикуется автоматически через ~0.8 с после того, как вы перестали печатать
(или сразу по кнопке «Опубликовать»). Панель диагностики открывается и по клику
на индикатор связи в правом верхнем углу.

## Устойчивость к блокировкам

Страница держит связь сразу с тремя независимыми брокерами:

| Брокер | Адрес | Порт |
|---|---|---|
| HiveMQ | `broker.hivemq.com` | 8884 |
| EMQX | `broker.emqx.io` | 8084 |
| Mosquitto | `test.mosquitto.org` | 8081 |

Редактор публикует во все, до которых дотянулся, читатель слушает все сразу и берёт
самое свежее сообщение. Если сеть режет один порт — выручает другой, и текст при этом
не расходится между брокерами.

**Но если сеть выпускает наружу только 80 и 443** (типичная закрытая корпоративная сеть),
не пройдёт ни один: все три порта нестандартные. Симптом — страница открывается,
но в углу «нет связи», а в диагностике все строки красные. Лечится только сменой
транспорта на что-то, работающее по 443 — см. Firebase ниже.

## Настройка своей копии

В `index.html` вверху скрипта:

```js
const ROOM = "73beefa132ff2d64";
```

`ROOM` — ваш личный канал. У всех, кто должен видеть один и тот же текст, он обязан
совпадать. Своё значение генерируется так:

```bash
openssl rand -hex 8
```

## Что важно понимать про ограничения

- **Брокеры публичные и без авторизации.** Кто откроет исходный код страницы (а он открыт
  всегда, это статический сайт), увидит `ROOM` и технически сможет писать в тот же канал.
  Ссылка `#admin` — не защита, а переключатель режима. Для «доски объявлений» это нормально,
  для чего-то ответственного — Firebase ниже.
- **Не публикуйте пароли и личные данные** — трафик идёт через чужие бесплатные брокеры.
- Retained-сообщение живёт на брокере, но публичные брокеры ничего не гарантируют:
  после долгого простоя или перезапуска текст может пропасть — достаточно опубликовать заново.
- Размер текста лучше держать в пределах нескольких сотен килобайт.

## Вариант понадёжнее: Firebase Realtime Database

Решает сразу обе проблемы: работает по 443 порту (проходит через закрытые сети)
и даёт настоящие права доступа — писать сможете только вы. Бесплатного тарифа хватает с запасом.

1. Создайте проект на <https://console.firebase.google.com>, добавьте Realtime Database.
2. Правила базы — читать всем, писать только авторизованному:

```json
{
  "rules": {
    "note": {
      ".read": true,
      ".write": "auth != null && auth.uid === 'ВАШ_UID'"
    }
  }
}
```

3. В `index.html` замените блок с подключением к брокерам на:

```html
<script type="module">
import { initializeApp } from "https://www.gstatic.com/firebasejs/10.12.2/firebase-app.js";
import { getDatabase, ref, onValue, set } from "https://www.gstatic.com/firebasejs/10.12.2/firebase-database.js";

const app = initializeApp({ /* конфиг из консоли Firebase */ });
const noteRef = ref(getDatabase(app), "note");

onValue(noteRef, (snap) => {
  const data = snap.val() || { text: "", ts: 0 };
  /* render(data.text, data.ts) или подставить в textarea */
});

// публикация:
// set(noteRef, { text: input.value, ts: Date.now() });
</script>
```

Разметка и стили не меняются — меняется только транспорт.

## Разработка

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000/?diag=1#admin` в одном окне и `http://localhost:8000/` в другом.

Публикация изменений — обычный push, Pages пересобирается за минуту:

```bash
git add -A && git commit -m "..." && git push
```
